# Comparative spatial metabolomics of the retropharyngeal gland

## Intro 
This repo contains the code required to reproduce the spatial metabolomics data results of the manuscript 'Spatial transcriptomics of the upper aerodigestive tract reveals previously unrecognised retropharyngeal salivary gland'.

## Repository contents
- `code` contains all notebooks needed to reproduce the analysis
- `generate_figure_source_csv.ipynb` contains code to save the underlying data for each plot created from this analysis
- data will be available on zenodo
